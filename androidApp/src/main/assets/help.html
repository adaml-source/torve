Help & Documentation

Getting Started

StreamVault is a media companion app that brings together your streaming sources, IPTV playlists, and media tracking services in one place.

Setting Up Debrid

Go to Settings > Debrid Service to connect your debrid provider (Real-Debrid, AllDebrid, Premiumize, or TorBox). You can use either an API key or device authorization.

Adding IPTV Playlists

Navigate to the IPTV tab and tap the + button to add a playlist. StreamVault supports:

  • M3U playlists - Paste an M3U URL
  • Xtream Codes - Enter your server, username, and password

Installing Addons

Go to Settings > Addons to manage Stremio-compatible addons. You can install addons by pasting their manifest URL.

Connecting Trakt

In Settings > Trakt.tv, enter your Trakt Client ID and Secret, then authorize via device code. This enables watch tracking, scrobbling, and syncing your watch history.

Connecting SIMKL

In Settings > SIMKL, enter your SIMKL Client ID and authorize via device code to sync your watch history with SIMKL.

Kodi Remote

Add your Kodi devices in Settings > Kodi Remote. Enter the device name, IP address, and port (default 8080). Use the Test button to verify the connection.

External Players

When you resolve a stream, the action menu lets you play in external apps like VLC, MX Player, or any other installed video player.

# Torve Sandbox Smoke Kit

Self-contained smoke for the desktop updater (B4) + onboarding (Fix A+B+E)
in one Windows Sandbox session.

## What's in this folder

| File | Purpose |
|------|---------|
| `Torve-1.0.6.msi` | The "old" version installed first inside the Sandbox. |
| `Torve-1.0.7.msi` | The target version the appcast points at; updater downloads + installs this. |
| `start-host.ps1` | Run on the host: starts an HTTP server + cloudflared HTTPS tunnel and writes `appcast.xml`. |
| `sandbox.wsb` | Double-click to launch Windows Sandbox with this folder mapped to `C:\smoke`. |
| `sandbox-run.ps1` | Run inside the Sandbox: installs 1.0.6, sets `TORVE_UPDATE_FEED`, launches Torve. |
| `appcast.xml` | Generated by `start-host.ps1` once the tunnel URL is known. |
| `feed-url.txt` | Generated; `sandbox-run.ps1` reads it so you don't have to copy/paste the URL. |
| `cloudflared.exe` | Auto-downloaded on first run of `start-host.ps1`. |

## Steps

### 1. Host machine

Open a PowerShell window in this folder and run:

```powershell
cd C:\Users\Anwender\StudioProjects\streamvault\smoke-kit
.\start-host.ps1
```

Wait until it prints:

```
============================================================
 SMOKE READY
============================================================
 Appcast URL :  https://<random>.trycloudflare.com/appcast.xml
 MSI URL     :  https://<random>.trycloudflare.com/Torve-1.0.7.msi
```

Leave that window open — closing it tears down the tunnel.

### 2. Launch the Sandbox

Double-click `sandbox.wsb` from File Explorer. A fresh Windows Sandbox
window opens with `C:\smoke` mapped from this folder.

### 3. Inside the Sandbox

Open PowerShell inside the Sandbox and run:

```powershell
cd C:\smoke
.\sandbox-run.ps1
```

It will:
1. Install `Torve-1.0.6.msi` silently.
2. Set `TORVE_UPDATE_FEED` to the cloudflared URL.
3. Launch Torve.

### 4. Manual checks once Torve opens

**Onboarding (Fix A+B+E):**
- Sign in (or skip auth).
- Confirm the post-auth screen shows the **Panda-primary hub**: a single
  "Set up with Panda" CTA + a "Skip for now" secondary action. No
  four-card category grid.
- Click **Skip for now** → lands on Home.
- Confirm Home shows the **zero-source empty state** with two CTAs:
  "Set up sources" and "Sync your watchlist with Trakt". No blank Home.

**Updater (B4):**
- Open Settings → About → **Check for updates**.
- Banner reports **Update available: 1.0.7**.
- Click **Download & install**.
- Watch progress bar → handoff phase → msiexec window flashes.
- Re-launch Torve from Start Menu. About should now show **1.0.7**.

### 5. Tear down

- Close Torve in the Sandbox.
- Close the Sandbox window (everything inside is wiped).
- On the host PowerShell window, press **Ctrl+C** to stop the tunnel
  + local HTTP server.

## What this does NOT cover

- **Multi-user isolation**. That work was just landed in `shared/` and
  isn't in either MSI yet. Needs another version bump + rebuild + a
  second smoke pass.
- **Side-by-side install bug** (#7). The known issue where 1.0.6 isn't
  removed during 1.0.6 → 1.0.7 upgrade. Watch for it during step 4 —
  if both versions show in `Add or remove programs`, that bug is still
  live.

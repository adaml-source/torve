Extensions

Manage your installed extensions. Extensions sync across all your signed-in devices.

How extensions work
  1. Get a manifest URL from the extension provider you choose.
  2. If setup is required, complete it with that provider and copy the personal manifest URL it supplies.
  3. Paste the URL below to install it on your account. On iOS, use Settings → Libraries & extensions → Extensions → Preview link.

A manifest is JSON data. Opening it in a browser displays JSON; paste its URL into Torve to install the extension.

Compatible extensions can provide catalogues, metadata, subtitles and playback sources. Some playback providers manage debrid or Usenet accounts on their own websites and return playable video links.

Add extension

Paste the manifest URL supplied by your chosen extension provider. No external extensions are installed automatically.

About extensions

Extensions are added from a provider’s manifest URL. They can add catalogues, metadata, subtitles and playback sources.

Built-in identifies features included with the app. External identifies extensions installed from a URL, including those hosted by Torve.

Each external extension is operated by its provider. The External label does not establish independence, endorsement or verification. Use sources you are authorized to access.

Bring your own lawful sources and media. 01 Get Downloader On your Fire TV, open Find → Search. Search for Downloader by AFTVnews and install it from the Amazon Appstore. 02 Allow Downloader to install Torve Open Settings → My Fire TV → Developer Options → Install Unknown Apps. Enable permission for Downloader . Can’t see Developer Options? Open My Fire TV → About, select your device name seven times, then go back. On some Fire TV televisions, use Device & Software instead of My Fire TV. Older Fire OS versions may call the setting Apps from Unknown Sources. 03 Enter the address and install Open Downloader. Enter torve.app/firetv in its Home URL field and select Go. On this page, select Download Fire TV APK , then choose Install and Open . You can also use the official APK link on this page in Downloader. Before you start This guide is for Android-based Fire OS devices that support installing APKs. Vega OS models do not support this installation method. Menu names vary by model. Downloader is missing from Install Unknown Apps Check for Fire TV updates under Settings → My Fire TV → About → Check for Updates, then restart. A Fire TV Settings bug has affected this permission list. If the option is still missing, contact Torve support with your device model and OS version. Check the download Download the official Torve APK hosted at torve.app. Verify the application name before installing. You can compare the file with its published SHA-256 checksum .
